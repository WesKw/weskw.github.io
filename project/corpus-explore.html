A project I did at ALCF over the summer. It attempted to determine if token orderings for training affected downstream LLM task performance. The final result ended up being unclear, but for the most part it seemed that token orderings did not significantly impact downstream task performance. However, I trained on fairly small models, and did not use as much data as I likely should have. I think this project would need to be repeated with a lot of tweaks before I could say anything conclusive. The full write-up is here.
